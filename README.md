# Shield Fire Protection

A concept website for a fire protection inspection and maintenance company, built as an unpaid portfolio project by [Pachet Web Design & Automation](https://www.pachetdigital.ca).

**Live:** https://pachets13.github.io/fire-protection-demo/
**Case study:** https://www.pachetdigital.ca/work/fire-protection-redesign

## About this build

Shield Fire Protection is a fictional company. The project began as a speculative redesign of a real inspection firm's site, and every identifying detail was replaced before publishing. The name, the phone number `(204) 555-0100`, the address, and all photography are invented or stock. Any resemblance to a real business is not intended.

The redesign leads with trust signals. Buyers in a compliance industry are checking whether a vendor's paperwork will hold up, so certifications and licensing carry the page rather than sitting in a footer.

## Stack

Astro 4 and Tailwind CSS, with Inter self-hosted rather than loaded from a CDN. Deploys to GitHub Pages from the `gh-pages` branch via `npm run deploy`.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
```

This repository carries a single commit by design. The history was squashed to remove the real business details that the earlier commits contained.
